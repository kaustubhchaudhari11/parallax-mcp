What to keep in mind

Valid pairs

15/15 counts valid pairs in the protocol pilot. It is not a reliability score for agents in general.

One candidate set

The 1 basis-point result covers 499 and 501 only.

One checkpoint

Control repeats share one checkpoint draw. No p-value is reported.

H1 irrelevance follows the decision rule. A model may still read a field that rule ignores. H3 scores the written decision. It does not score an action the tools carried out.
