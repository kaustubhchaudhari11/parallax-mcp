What happens when the evidence changes?

These studies keep the agent, prompt, and model settings fixed, then change one tool observation.

The counts come from the sanitized catalog. The three studies stay separate. One model configuration, gpt-6-luna, produced the research rows.

Does the agent adapt?

What to keep in mind

Early research

The published demo uses a small synthetic incident dataset and one live model configuration.

Different comparison methods

LangGraph resumes from a checkpoint. CrewAI uses controlled fresh reruns.

Read the research limitations

The protocol pilot is 15 pairs, five for each question, in study exp-3a-da9fc3022a77b55b. The intervals are wide. The 24-scenario evaluation has not been run. No p-value is reported.

Control repetitions in ctl-3fcf26ebf34c7ce4 share one checkpoint draw. Each Decision X-Ray candidate in xray-547963e428ed516b is one draw. That search enumerated 499 and 501 only.

The live rows use gpt-6-luna. Scripted local examples are a separate study. A match on these fixtures is not a reliability guarantee for every agent. The website does not execute an uploaded agent.

The task is a synthetic incident. H1 irrelevance follows the decision rule, and a model may still read a field that rule ignores. H3 scores the written decision. It does not score an executed action.

A paper is not published. There is no DOI. The method is the repository protocol. Reproducibility uses Python 3.12, uv.lock, MCP Python SDK 2.3.0, and the hashes stored with each study. Raw traces stay in local runs/. How the comparison is built.
