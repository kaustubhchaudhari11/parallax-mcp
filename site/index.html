Why does this matter?

An agent can return the right label and still miss the evidence behind it. PARALLAX changes one tool observation and records what the decision does.

What PARALLAX does

Three steps. One declared change.

  1. 01

    Capture the evidence

    Save the tool response the agent actually received.

  2. 02

    Change one observation

    Edit one validated field. Keep the prompt and settings fixed.

  3. 03

    Compare the decisions

    Read both decisions against the rule for that experiment.
