From a checkout to a report

  1. 1

    Install PARALLAX

    Use Python 3.12 and uv, from the repository root.

  2. 2

    Connect your agent

    Point the spec at a factory in this checkout, outside src/parallax.

  3. 3

    Choose the evidence

    Name one field you may edit, and the value to try.

  4. 4

    Define the behavior

    Say which label you expect before the edit, and which label you expect after it.

  5. 5

    Run the evaluation

    Dry-run first. It sends no model request. Then run the local test.

  6. 6

    Read the report

    The JSON lands in byoa-runs/. That folder is gitignored.

This website does not run your agent. A factory runs locally, with the permissions of the checkout you trust. The path check is not a sandbox.
